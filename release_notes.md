## Playtube 2.2.1

- **Jam verbindet auch hinter zickigen Routern:** Findet Windows `jam.fojadrachi.de` nicht (manche Router merken
  sich bei neuen Adressen eine Zeit lang „gibt es nicht“), fragt Playtube die Adresse verschlüsselt bei
  Cloudflare-DNS nach und verbindet trotzdem. Vorher zeigte der Jam-Tab dann „Keine Verbindung zum Jam-Server“.

Alles Weitere wie in 2.2.0 (Playtube Jam). **Installieren:** `Playtube-Setup-2.2.1.exe` laden und starten –
ersetzt jede ältere Playtube. Playtube aktualisiert sich auch von selbst.

## Playtube 2.2.1

- **Jam connects behind stubborn routers too:** if Windows can't find `jam.fojadrachi.de` (some routers cache
  "does not exist" for new addresses for a while), Playtube looks the address up via encrypted Cloudflare DNS
  and connects anyway. Previously the Jam tab showed "Can't reach the jam server".

Everything else as in 2.2.0 (Playtube Jam). **Install:** run `Playtube-Setup-2.2.1.exe` – it replaces any older
Playtube. Playtube also updates itself.
